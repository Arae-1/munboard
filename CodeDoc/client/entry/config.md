# Client Configuration

The configuration file `.config.autogen.json` is auto-generated during the build process. It provides build metadata and the runtime environment mode.

## File Structure

The file contains a single JSON object with two top-level keys:

```json
{
    "meta": {
        "version": "1660cfe6-dirty",
        "buildDate": "Fri, 31 Jul 2026 11:56:28 GMT"
    },
    "environment": "production"
}
```

## Fields

| Field                | Type   | Description                                      |
|----------------------|--------|--------------------------------------------------|
| `meta.version`       | String | The build version identifier (Git hash + dirty). |
| `meta.buildDate`     | String | The date and time of the build.                  |
| `environment`        | String | The runtime environment: `"production"` or `"development"`. |

## Usage in main.js

The `main.js` file imports this configuration through `./config.js` (which resolves to the auto-generated JSON). It uses the `environment` field to decide whether to connect a live-reload WebSocket.

## Notes

- The file extension `.autogen.json` indicates it is not hand-authored. Do not edit it manually.
- The `config.js` wrapper likely exists as an intermediary module generated by the build system. If it does not exist as a standalone file, it is resolved by the bundler (Browserify/Webpack) to load this JSON.
